## Data checks and caveats
- **Verified:** All 85 quadrant labels match the RS ≥100 / momentum ≥100 thresholds (0 mismatches). Lead plus lag weeks never exceed 12. Consistency score equals lead weeks / 12 (XLK: 2/12 = 16.7).
- **`angle_deg` is not the position angle.** It matches atan2(momentum−100, RS−100) in only 4 of 85 names. I treated it as the heading of the latest move (negative means momentum falling), which the file does not confirm. The "rolling over" calls above lean on this, so confirm the definition.
- **Non-standard momentum scale:** It runs 69–180, versus roughly 94–106 for a typical JdK RRG. Use it for ranking only, not against standard RRG thresholds or distances.
- **`velocity_direction` is undefined in the file.** I assumed it means the change in the speed of RRG movement.
- **Missing inputs:** The file has no price data or tail history, only a snapshot plus 12-week counts. "Leading" means outperforming SPY, not rising in absolute terms. Futures-based funds (USO, UNG, COMT, DBC) also carry roll effects that RS alone will not show.
